# data/

## Committed (small, derived, redistributable)

- `area_stats.json` — approved/rejected/excluded counts and approval rate per
  borough and per Opportunity Area. Aggregated only; contains no individual
  application records.
- `london_borough_boundaries.geojson`, `london_oa_boundaries.geojson` —
  simplified WGS84 boundary polygons, generated by `scripts/build_area_lookups.py`.

## Gitignored — you generate these yourself

### `raw/ONSPD_FEB_2026/`

The ONS Postcode Directory. Download the latest release from the
[ONS Open Geography Portal](https://geoportal.statistics.gov.uk/) (search
"ONS Postcode Directory" or "NSPL"), unzip it, and place it here so that
`raw/ONSPD_FEB_2026/Data/ONSPD_FEB_2026_UK.csv` exists (adjust the folder/file
name in the script args if you're using a different release).

### `postcode_borough_lookup.csv`, `postcode_oa_lookup.csv`

Generated by `scripts/build_area_lookups.py` — every live Greater London
postcode mapped to its borough and (if applicable) Opportunity Area. Not
committed: hundreds of thousands of rows, trivial to regenerate, and there's
no reason to track a full ONSPD re-export in git history.

### A local planning-applications database (not stored under `data/`)

`scripts/build_stats.py` expects a sqlite database with an `applications`
table (`payload` column containing JSON with `postcode` and `app_state`
fields — this repo was built against a
[PlanIt](https://www.planit.org.uk/)-derived export). Point `--db` at wherever
that file lives on your machine; it's never copied into the repo.
